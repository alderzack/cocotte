# Cocotte — le minuteur à œufs qui caquette

Web-app (à ajouter à l'écran d'accueil du téléphone) pour cuire ses œufs :

- **Coque** 3 min · **Mi-mollet** 5 min · **Mollet** 6 min · **Dur** 10 min
  (œufs plongés dans l'eau qui bout déjà)
- Un appui sur une cuisson lance le minuteur, avec pause et annulation
- À la fin : la poule caquette jusqu'à « Stop la poule », le téléphone vibre (Android)
- Un fun fact différent sur l'œuf à chaque utilisation
- Un menu de recettes d'œufs, avec bouton pour lancer le bon minuteur
- Fonctionne hors ligne une fois ouverte

## Utilisation

Ouvrir l'app sur le téléphone, puis :
- **iPhone** (Safari) : Partager → « Sur l'écran d'accueil »
- **Android** (Chrome) : menu ⋮ → « Ajouter à l'écran d'accueil »

Garder l'app ouverte pendant la cuisson : l'écran reste allumé pour que la poule puisse chanter.
